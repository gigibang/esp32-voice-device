## 术语词典（每个英文 term 都翻译成"人话 + 干啥用"）

| 英文 term | 通俗说明 | 它管什么 |
|---|---|---|
| **ESP32-S3** | 主控 CPU 型号 | 玩具的"大脑" |
| **R8** 后缀（如 ESP32-S3R8） | 自带 8MB PSRAM 的封装 | 省一颗外接芯片 |
| **N8R8** | 自带 8MB Flash + 8MB PSRAM | 合封更省板面 |
| **Flash** | 闪存 / "硬盘" | 存固件、提示音、图片，**关电不丢** |
| **PSRAM** | 运行内存 / 类似手机 RAM | 程序跑时占用，**关电就清** |
| **LCD** | 液晶屏 | **背光照亮，黑色也是亮的**（旧手机屏） |
| **AMOLED** | 自发光屏 | **每个像素自己发光，黑色真黑**（新手机屏） |
| **墨水屏 (e-Paper)** | 电子纸 | **不发光，关电也能显示**（Kindle） |
| **触摸 IC**（CST816 / CST9217 / FT6336）| 触摸控制芯片 | 把手指位置转成数字坐标 |
| **单点 / 多点** | 一次能识别几根手指 | 多点能做"捏合放大" |
| **mic** | 麦克风 | 听你说话 |
| **双麦阵列** | 两个麦克风 | 识别说话**方向** + 嘈杂环境降噪 |
| **ES7210** | 麦克风阵列 ADC，为回声消除（**AEC** = Acoustic Echo Cancellation）提供参考通道 | 它本身不做消除，消除跑在 S3 的 ESP-SR 里；但没有这颗提供参考信号，喇叭外放时**麦会收到自己的声音**，导致嗡嗡自激 |
| **ES8311 codec** | 音频编解码芯片（**Co**der + **Dec**oder）| 数字音频 ↔ 模拟声音的转换 |
| **NS4150B 3W 功放** | 音频放大器（amplifier） | 放大音量让喇叭拉得响（**3W = 3 瓦，越大越响**） |
| **AXP2101 PMIC** | 电源管理芯片（**P**ower **M**anagement **IC**） | 管充电、多路输出、**精确算电量**、深睡省电 |
| **QMI8658 IMU** | 六轴运动传感器（**I**nertial **M**easurement **U**nit） | 感应**摇一摇 / 翻转 / 走路** |
| **RTC PCF85063** | 实时时钟芯片（**R**eal-**T**ime **C**lock） | **断电也记时间**，能定时叫醒主控 |
| **SHTC3** | 温湿度传感器 | 测**温度 + 湿度** |
| **Micro SD** | 小内存卡槽 | 插**手机那种小 TF 卡**扩容 |
| **TCA9554 IO 扩展** | IO 扩展芯片 | 主控 GPIO 不够用时**多 8 个脚** |
| **GPIO** | 通用输入/输出脚 | 接传感器、按键、LED 都用 |
| **MX1.25** | 一种小白色 **2 针插座**（接插件型号） | 电池和外接喇叭都用这种，1.25mm 间距 |
| **PH2.0 / SH1.0** | 另外两种**针距**的接插件 | 跟 MX1.25 不通用，**别买错** |
| **焊盘 (pad)** | 板上**裸金属点** | 接东西要**烫锡**焊上 |
| **排母 / 排针** | **塑料插针座** | 直接**插杜邦线**即可（方便） |
| **mAh** | 电池容量单位（毫安·时） | 数字大**越耐用** |
| **PMIC** | Power Management IC 缩写 | 见 AXP2101 |
| **AEC** | Acoustic Echo Cancellation（回声消除）缩写 | 算法跑在主控上，需要 ES7210 提供参考通道 |
| **codec** | Coder/Decoder 缩写 | 见 ES8311 |
| **IMU** | Inertial Measurement Unit 缩写 | 见 QMI8658 |
| **OTA** | Over-The-Air（无线升级） | 玩具能通过 WiFi 自己更新固件 |
| **NTP** | Network Time Protocol | 联网时自动对时 |

## 一句话记住三块板的"性格"

- **LCD-1.54** = **"声音最响的桌面方盒"**——耳朵好、能动、喇叭最响、有卡槽、屏一般、外壳一般
- **1.75C** = **"长得最帅的挂件圆盘"**——铝合金壳、屏最炫、电池管得最准、硬盘最大
- **Touch-ePaper-1.54 V2** = **"永远在线的桌面小相框"**——不耗电、记时间、测温湿度、有插座方便接东西、但只有一只耳朵且不能摇

## 三块各自适合干什么

- **LCD-1.54**：**桌面 AI 音箱** / 能响的提醒器 / 桌上的小宠物 / 学习 voice toy 量产音频精髓的练手板
- **1.75C**：**挂胸前的 AI 挂件** / 接近量产的小产品原型 / 高质感成品演示
- **Touch-ePaper-1.54 V2**：**桌面信息小屏**（天气、便签、时钟、温湿度）/ "会偶尔说话的电子相框" / 几个月不充电的低存在感小玩具

## 喇叭真实情况（容易误判的点）

**三块全部"板载小喇叭 + MX1.25 外接接口"双方案**——不是非此即彼。

| | 板上喇叭 | 独立功放 | 大致响度 | 能不能换大喇叭 |
|---|---|---|---|---|
| LCD-1.54 | ✓ | **NS4150B 3W Class-D** | **最响** | ✓ MX1.25 接口 |
| 1.75C | ✓ | 无（靠 ES8311 自驱动 ~1W） | 中等，金属壳音色干净 | ✓ |
| Touch-ePaper-1.54 V2 | ✓ | 无（~1W） | 小但够日常提醒 | ✓ |

实际体验：**LCD-1.54 能当桌面音箱开很响**，1.75C 适合贴身距离听人声，墨水屏那块发个提示音或读一句话都够。

## 墨水屏 V1/V2 避坑（关键）

shop 页**完全没说**有两个版本，wiki 里才能看到：

| | **V1（老版）** | **V2（2025-11 后）✓ 必须这个** |
|---|---|---|
| 主控 | ESP32-S3FH4R2 | ESP32-S3-PICO-1-N8R8 |
| Flash | **4MB**（XiaoZhi 固件都装不下） | **8MB** |
| PSRAM | **2MB**（LVGL 跑不起来） | **8MB** |

**下单前必做**：
1. 问客服或看货号，确认主控是 **ESP32-S3-PICO-1-N8R8**
2. 看 shop 页是否标注 "V2" / "2025年11月以后"
3. 收货后确认：`esptool chip-id` 只报芯片家族（V1/V2 都是 ESP32-S3，区分不了），要用 `esptool flash-id` 看实际 Flash 容量 —— 4MB = V1，8MB = V2

## MX1.25 电池购买指南

所有候选都是 **MX1.25 2P 锂电池接口 3.7V**。

淘宝搜：`3.7V 锂电池 MX1.25 2P 保护板`

| 容量 | 体积参考 | 价格 | 适用 |
|---|---|---|---|
| 500mAh | 30×20×5mm | ¥10–15 | 薄玩具 / 挂件（1.75C 自带这个）|
| 1000mAh | 50×30×6mm | ¥15–20 | 平衡续航/体积 ← 推荐（LCD-1.54 自带）|
| 2000mAh | 60×40×7mm | ¥25–30 | 大玩具 / 长续航 |

注意事项：
- 一定要 **MX1.25 2P** 接头（**别买 PH2.0 / SH1.0**，针距不同插不上）
- **红线 = 正极，黑线 = 负极**（反接会烧 PMIC）
- 必须带**保护板**（防过充过放），现在淘宝默认都带
- 板子带 USB-C 充电管理，**边充边用没问题**

## 跟手上 Spotpear muma 的升级关系

手上的对照设备是 Spotpear sp-esp32-s3-1.54-muma：
- 1.54" LCD ST7789 240×240
- ES8311 codec ✓ 但**单麦 + 无 ES7210 AEC + 无 IMU**
- 基础充电 IC（无 AXP2101）

**LCD-1.54 = Spotpear muma 的"豪华升级版"**：
- 屏完全一样大小 → 软件能直接平移
- 多了**第二只麦克风 + ES7210 AEC + QMI8658 IMU + NS4150B 3W 功放**
- 是真正能感受到"为什么量产 voice toy 要这些芯片"的对照实验板

## 调研工具笔记（给未来的自己）

数据源优先级：

1. **docs.waveshare.net wiki** — 最权威，技术规格 + 引脚 + 例程
   - URL 模式：`https://docs.waveshare.net/<product-slug>/`
   - 用 `?variant=<具体-SKU>` 切换 SKU
   - **会暴露 V1/V2 差异（shop 页不会说）**
2. **CDN 产品图原图**（特别是资源贴纸图） — 最直观
   - URL 模式：`https://www.waveshare.net/photo/development-board/<folder>/<filebase>-N.jpg`
   - 墨水屏在 `/photo/LCD/`
   - 文件夹名 ≠ 产品 slug（LCD-3.5-C 在 `ESP32-S3-Touch-LCD-3.5` 文件夹）
   - 资源贴纸图通常是 img-3 或 img-5
3. **shop 页** — 营销描述 + 配件清单 + 价格 + SKU 变体
   - URL：`https://www.waveshare.net/shop/<product-slug>.htm`

方法论：
- 纯文本抓取（HTML → markdown）**会丢掉图片**，而板载资源贴纸图恰恰是最准确的一手资料
- 解法：从 CDN 直接 `curl` 产品原图下来逐张看 —— 贴纸上印的 IC 型号比商品描述可靠得多
- 三个数据源交叉验证，避免单一来源误判

常见误判模式（这次踩过）：
- 表格里"喇叭打勾"可能是**接口**也可能是**板载**——必须看图
- "AMOLED-X.XX" 的 -C 后缀版**往往砍配置**（少 SD/RTC 等）
- 廉价"-C/B"变体可能换主控（如墨水屏 V1 → V2 换了主控）
- **同名不同档**：LCD-1.85C 砍掉音频套件 ≠ LCD-1.54 保留完整音频套件
