## 78/xiaozhi-esp32

The devices studied in this repository run [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32), an
open-source ESP32 voice-assistant firmware licensed under the MIT License.

[`docs/protocol.md`](docs/protocol.md) documents that project's wire protocol, read from its published
source at commit `417f52d7597b85f3dfc6f5283bdc66df34fbd5fe`. The binary framing struct definitions in
§2.3 of that document are reproduced from `main/protocols/protocol.h`; everything else is a
description written from reading the source.
